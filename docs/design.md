# one candle — 設計のまとめ(2026-10-23 専門家3人の相談から)

## キャンドル(キャンドルの専門家)
- 洋ろうそくの炎は小さく、形が決まっている(綿芯で 高さ 2.5〜3.5cm)。和ろうそくのような「息」はしない。**動かないことが洋ろうそくらしさ**。
- 青い根元は うすく小さく。いちばん明るいのは 高さの3〜4割。蜜ろうは少し黄色く明るい。
- ガラスの中(風よけ・ランタン・グラス・器)は 揺れを 0.35〜0.7倍に。木の芯は 横に広い低い炎で、ときどき明るさが小さく跳ねる(音はなし)。
- 3つの炎は ゆっくり同じように揺れる(ばらばらにしない)。
- 最初は ピラー。最後は いちばん小さい ティーライトで 眠りにつなげる。
- 入れなかったもの: アドベントリース・ハヌキヤ・ルシアの冠(何本も要る、人の姿が入る)。教会・メキシコのグラスには 絵や文字を入れない。

## 部屋(インテリア・デザイナー)
- 10。1つずつ 丁寧に描けて、似た「茶色い壁」にならない数。ろうそく20 × 部屋10 = 200通りで十分。
- 色の散らばり: 冷たい(冬の窓・礼拝堂・藍)/ あたたかい(北欧・トスカーナ・Log House)/ まざる(Paris・書斎・モロッコ・ハノク)。
- 台の映り込み: 強い(Paris の大理石・モロッコの真鍮の盆・藍の黒い石)/ 中(冬の窓・書斎・ハノク)/ なし(礼拝堂の石)。
- 部屋の絵は 少しぼかす(写真の背景ぼけ)。主役はキャンドル。小物は 炎の近くに置いて ふちが光を拾うように。
- 鏡・窓ガラスには 炎が うっすら映る。夜の窓・韓紙の戸は 外の光で ほんの少し明るい。
- あとで足すなら: フィリピンのカピス貝の窓、メキシコの日干しれんがの壁。

## 使いやすさ(UI/UX)
- ボタン5つ(Candle / Room / Music / Sleep / Light)。部屋を「ろうそく」の板の中のタブにすると、お年寄りは気づかない。部屋は このアプリの売りなので隠さない。
- 英語は 5語と板の見出しだけ。選ぶ言葉・説明は日本語(どうなるかを伝える言葉は 日本語のほうが迷わない)。
- 選ぶ板は 写真+名前。キャンドルは たて長3列、部屋は よこ長2列(名前+国名)。選んでいるものは 琥珀色の枠。
- 見本は 実際の画面より明るくする(夜の画面のままだと ぜんぶ「暗いだんご」に見える)。部屋の見本は どれも同じ小さなキャンドル。
- ボタンが消えるまで 10秒(お年寄りは読むのに時間がかかる)。音の大きさのつまみは 28px。押せる所は 48px 以上。
